# AI Project Portfolio

Auto-updating portfolio and resume powered by GitHub Actions. Scans for new AI project repos daily and updates the portfolio site + resume.

## How It Works

```
You upload AI project → GitHub Actions detects it → Portfolio + Resume auto-update
     (manual)              (daily cron, free)         (GitHub Pages, free)
```

No AI APIs needed. No Claude. Just Python reading JSON and generating HTML.

## Setup (One-Time)

### 1. Create this repo on GitHub

Create a new repo called `ai-portfolio` (or any name) and push these files to it.

### 2. Create a Fine-Grained Personal Access Token

1. Go to https://github.com/settings/tokens?type=beta
2. Click **"Generate new token"**
3. Name: `portfolio-scanner`
4. Expiration: 90 days (you'll renew)
5. Repository access: **All repositories** (read-only is enough)
6. Permissions → Repository permissions:
   - Contents: **Read-only**
   - Metadata: **Read-only**
7. Click **Generate token** and copy it

### 3. Add Secrets to this Repo

Go to this repo → Settings → Secrets and variables → Actions → New repository secret:

- `PORTFOLIO_TOKEN` = your token from step 2
- `GH_USERNAME` = your GitHub username

### 4. Enable GitHub Pages

Go to Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder: `/docs` → Save

### 5. Done!

- Portfolio lives at: `https://YOUR_USERNAME.github.io/ai-portfolio/`
- Resume lives at: `https://YOUR_USERNAME.github.io/ai-portfolio/resume.html`
- Updates daily, or trigger manually from Actions tab

## How Projects Are Detected

The Action scans your GitHub account for repos starting with `ai-project-` and reads:
- `project-idea.json` — project metadata (title, category, tech stack, etc.)
- `report-data.json` — test results, pipeline stats (optional)

Both files are auto-generated by the Daily AI Pipeline on your local machine.

